# Бинарная сериализация

Идея заключается в том, чтобы описать структуру бинарных данных (например, формат файла или сетевого пакета) на специальном языке (DSL - Domain Specific Language), а затем скомпилировать это описание в:

1. **Структуры данных C++** (классы, структуры) для удобного представления данных в памяти.
2. **Код для сериализации** (записи структуры в бинарный формат).
3. **Код для десериализации** (чтения бинарных данных в структуру).
4. **Валидацию данных** (проверку целостности и соответствия формату).

Из готовый инструментов известен только [[Kaitai Struct]] и [[bit syntax]] в Erlang, но для генерации С++ кода оба принципиально не подходят.
