# Format
## продвинутое [[Форматирование строк]]

Модуль `Format` представляет собой один из наиболее мощных инструментов OCaml для структурированного форматирования вывода. В контексте разработки компиляторов он находит применение в генерации читаемого кода, pretty-printing AST, создании диагностических сообщений и документировании.

Базовый механизм модуля Format основан на форматирующих функциях и специальных управляющих символах:

```ocaml
open Format

(* Простое форматирование *)
let print_ast_node node_type content =
  printf "@[<2>%s: %s@]@." node_type content

(* Форматирование с отступами *)
let print_nested_structure name items =
  printf "@[<v 2>%s:@,%a@]@." 
    name 
    (pp_print_list pp_print_string) items
```

## Управление breaking space и отступами

Основная логика работы модуля строится на двух понятиях:
- **Боксы** (boxes)
	- Логические блоки, определяющие политику переноса строк для своего содержимого
- **Разрывы** (break hints)
	- Подсказки для механизма форматирования о том, где можно вставить пробелы или перенести строку

**Типы боксов**

- **Горизонтальный бокс (`open_hbox`)**: Разрывы внутри него **никогда** не приводят к переносу строки
    
- **Вертикальный бокс (`open_vbox`)**: Каждый разрыв внутри него **всегда** приводит к новой строке
    
- **Горизонтально-вертикальный бокс (`open_hvbox`)**: Весь блок выводится в одну строку, если помещается; иначе каждый разрыв приводит к новой строке
    
- **Горизонтальный ИЛИ вертикальный бокс (`open_hovbox` / `open_box`)**: Наиболее употребим. Разрывы переносят строку только если для содержимого не хватает места

**Типы разрывов**

- **`print_space ()`**: Выводит один пробел, если строка не переносится, или новую строку в противном случае. Эквивалентен `print_break 1 0`
    
- **`print_cut ()`**: Либо переносит строку, либо не выводит ничего. Эквивалентен `print_break 0 0`
    
- **`print_break nspaces offset`**: Универсальный разрыв. Если строка не переносится, печатает `nspaces` пробелов. Если переносится, то отступ новой строки будет равен `(текущий отступ бокса + offset)`

## Генерация кода

```ocaml
let pp_c_type fmt = function
  | `Int -> fprintf fmt "int"
  | `Float -> fprintf fmt "float"
  | `Pointer t -> fprintf fmt "%a*" pp_c_type t
  | `Array (t, size) -> fprintf fmt "%a[%d]" pp_c_type t size

let pp_c_declaration fmt (name, typ) =
  fprintf fmt "@[<hov 2>%a %s;@]" pp_c_type typ name

let pp_c_function fmt (return_type, name, params, body) =
  fprintf fmt "@[<v 2>%a %s(@[<hov>%a@]) {@,%a@]@,}" 
    pp_c_type return_type
    name
    (pp_print_list ~pp_sep:(fun fmt () -> fprintf fmt ",@ ") pp_c_declaration) params
    pp_c_statement body
```
