# Установка и настройка окружения

- [[opam]] — это стандартный менеджер пакетов для OCaml, который используется в том числе для установки компилятора и дополнительных библиотек:

```sh
bash -c "sh <(curl -fsSL https://opam.ocaml.org/install.sh)"
sudo apt install -uy bubblewrap
opam init -a
opam update
```

- настройка переменных среды:

`~/.profile` `~/.xsessionrc`:
```sh
# OCaml
test -r '$HOME/.opam/opam-init/init.sh' && . '$HOME/.opam/opam-init/init.sh' > /dev/null 2> /dev/null || true
eval $(opam env)
```

- создайте switch — изолированное окружение с конкретной версией компилятора и набором пакетов
```sh
opam switch list-available
opam switch list
```
```sh
opam switch create cs3110 ocaml-base-compiler.5.3.0
```
- активируйте его:
```sh
opam switch set cs3110 ; eval $(opam env --switch=cs3110)
```
- проверка
```sh
opam --version
ocamlc -v
```
```
2.4.1

The OCaml compiler, version 5.3.0
Standard library directory: /home/dev01/.opam/cs3110/lib/ocaml
```
- Установите основные инструменты для комфортной разработки:
```sh
opam install -y utop dune ocamlformat ocaml-lsp-server
```
