# Симмеричная сериализация

язык E включает штатные средства
- описания двоичных и текстовых форматов данных и протоколов
- генерацию кода симметричных парсеров (чтение и генерация данных)
	- включая не только текстовые парсеры,
	- но и бинарные симметричные (де)сериализаторы
	- в том числе потоковые парсеры/сериализаторы

прототипы:

- [[kaitai/Kaitai Struct]]
	- added serialization support (write mode) in its 0.11 release, allowing you to create or edit binary files according to your format specifications
	- write mode feature is currently available only for Java and Python (not applicable for embedded)
- [[Erlang]]:
	- встроенное сопоставление с бинарными шаблонами
	- bit syntax для генерации пакетов бинарных данных
- [[BinPAC]]/BinPAC++/Spicy
	- high level language for describing protocol parsers (generates C++ code)
	- не симметричный: генерация бинарных данных не поддерживается
