# Что такое OCaml?

**[[OCaml/OCaml|OCaml]]** (Objective Caml) — это современный строго типизированный функциональный язык программирования общего назначения с развитой системой модулей и объектно-ориентированными возможностями.

## Мультипарадигмальность

- Функциональное программирование
	- функции первого класса, каррирование
	- иммутабельные структуры данных
- Императивное программирование
	- мутабельные переменные, циклы, ссылки
- Объектно-ориентированное программирование
	- классы, наследование, полиморфизм
- Модульная система
	- [[oca/Модули|Модули]], сигнатуры, [[oca/Функторы|Функторы]]

## Статическая строгая типизация

```ocaml
(* Система типов выводит типы автоматически *)
let x = 5 + 3        (* x : int *)
let square x = x * x (* square : int -> int *)
```

## Мощное [[oca/Сопоставление с образцом|Сопоставление с образцом]]

- к переменным шаблона биндятся значения из совпавшей структуры/объекта
- проверяется что в сопоставлении перечислены все варианты

```ocaml
type shape = 
  | Circle of float
  | Rectangle of float * float

let area = function
  | Circle r -> 3.14 *. r *. r
  | Rectangle (w, h) -> w *. h
```

## Практическая направленность

- **Производительность**: компиляция в нативный код
- **Интероперабельность**: взаимодействие с C-библиотеками
- **Инструменты**:
	- **REPL** [[utop]],
	- менеджер пакетов [[opam]],
	- build-система [[dune]]
- Штатные средства синтаксического анализа, расширения синтаксиса (DSL) и метапрограммирования

## Почему хорош для разработки компиляторов?

- **Выразительность AST**:
	- [[oca/Алгебраические типы данных]] идеально подходят для представления синтаксических деревьев
	- **Эффективная работа с деревьями** (AST-преобразования)
- **Безопасность**:
	- система типов предотвращает многие ошибки на этапе компиляции
- **Хорошая производительность**
	- генерирует эффективный нативный код
- Высокоуровневость и [[автоматическое управление памятью]]
	- не требуется синтаксическая каша
	- не нужно следить за выделением/передачей/освобождением памяти
- **Возможностям метапрограммирования** через макросы и функторы

	- Роль сопоставления с образцом (в общем смысле, а не как особенности языков семейства ML) в теории компиляторов сильно недооценена. Наличие сопоставления с образцом в качестве функции языка реализации значительно упрощает задачу в отсутствие специализированной и полнофункциональной инфраструктуры

## Известные проекты на OCaml

- **CompCert**: верифицированный компилятор C
- **Coq**: система интерактивного доказательства теорем
- **Frama-C**: фреймворк для анализа C-кода
- **Hack** — язык программирования Facebook
- **ReasonML** — синтаксис OCaml для веб-разработки
- **Facebook Flow**: статический анализатор JavaScript
- ранние прототипы языка [[Rust/Rust|**rustboot**]] (2006-2009)
	- Разработчик: Грейдон Хор ([[people/Graydon Hoare]]) в Mozilla Research
- **MirageOS** — библиотечная ОС для облачных развертываний
- **HLVM** — виртуальная машина для высокоуровневых языков
- **Jane Street** — ведущий проп-трейдинг (крупнейший пользователь OCaml)
- **Citrix Systems** — финансовые аналитические инструменты
- **Bloomberg** — компоненты торговых систем
