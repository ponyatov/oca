# Комментарии

## OCaml

```ocaml
(* *)
```

- однострочные комментарии: нет, только блочные
```ocaml
(* Это однострочный комментарий *)
let x = 5 (* Можно комментировать после кода *)
```

- многострочные комментарии:
```ocaml
(* Это
   многострочный (* вложенный *)
   комментарий *)
```

## E

- shebang: используется как префикс для скриптов
	- первая строка текстового файла, начинающаяся с `#!`
		- `#!/usr/bin/env oca` или `#!/usr/bin/E`
- строчный комментарий:
	- `//`
- блочный комментарий:
	- `/**/`
