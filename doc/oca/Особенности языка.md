# Особенности языка

OCaml не навязывает единственную парадигму программирования, а гармонично сочетает несколько подходов, что делает его исключительно гибким. 

## Типизация

- **Статическая типизация:** Все типы проверяются на этапе компиляции, что позволяет отловить огромное количество ошибок до запуска программы.
    
- **Строгая типизация:** Неявные преобразования типов (например, между целым числом и строкой) запрещены. Это делает поведение программы более предсказуемым.
    
- **Вывод типов:** Компилятор сам определяет типы почти всех выражений. Вам почти никогда не нужно писать аннотации типов вручную, но при этом вы получаете все преимущества статической типизации.

- **Алгебраические типы:** Позволяют создавать сложные структуры данных, идеально сочетающиеся с сопоставлением с образцом.
	- **Вариантные типы (Sum types):** Позволяют определить тип, который может быть одним из нескольких вариантов.
    
	    - встроенный тип для nullable-значений: избавляемся от null hell
		    - `type option = None | Some of 'a` ()
        
		- встроенное определение списка
			- `type 'a list = [] | (::) of 'a * 'a list` ()
        
	- **Типы-произведения (Product types):** Например, кортежи и записи, которые группируют несколько значений вместе.

## Функциональная парадигма

- **Функции первого класса:** Функции являются такими же значениями, как числа или строки. Их можно передавать в качестве аргументов, возвращать из других функций и сохранять в структурах данных.
    
- **Неизменяемость по умолчанию:** Значения по умолчанию неизменяемы (immutable). Это упрощает рассуждение о коде, особенно в параллельном программировании.
    
- **Функции высшего порядка:** Поддержка функций, которые принимают или возвращают другие функции (как `map`, `filter`, `fold`).

## Сопоставление с образцом

Мощный и лаконичный механизм *для декомпозиции данных* и проверки условий.

- Заменяет громоздкие цепочки `if-else` или `switch`.
    
- Проверяется на полноту: компилятор предупредит, если вы рассмотрели не все возможные случаи.
    
- Работает с любыми типами данных: кортежами, списками, вариантами (variant types), записями.

## Система модулей

- **Модули:** Группируют связанные определения (типы, функции, подмодули).
    
- **Сигнатуры (Signatures):** Интерфейсы для модулей, которые определяют, что из модуля видно снаружи.
    
- **Функторы (Functors):** Функции от модулей к модулям. Позволяют создавать параметризованные модули (аналог generics, но на уровне целых модулей).
