## формат

пример кода:
```ocaml
let script_remotely (user : string) (host : string) (port : int) (script : string) =
  {%string|ssh %{user}@%{host} -p %{port#Int} %{Sys.quote script}|}
;;
```

- `%{expr}`
- `%{expr#Mod}`
- leftpad with `:n` spaces
	- `%{expr#Mod:int_expr}`
	- `%{expr#:int_expr}`
