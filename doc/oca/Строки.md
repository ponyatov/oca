# Строки

Строковые данные играют особую роль в разработке компиляторов — от обработки исходного кода до генерации диагностических сообщений и взаимодействия с внешними инструментами. OCaml предоставляет несколько подходов к работе со строками, каждый из которых находит своё применение.


## `string`: Базовые строки

- Создание строк
```ocaml
let s1 = "Hello, World!"
let s2 = "OCaml"
let empty_string = ""
```
- Конкатенация
```ocaml
let greeting = "Hello, " ^ "OCaml!"  (* "Hello, OCaml!" *)
```
- Доступ к символам по индексу
```ocaml
let first_char = "hello".[0]  (* 'h' *)
```

## Строковые литералы и экранирование

Базовые строки в OCaml используют двойные кавычки и поддерживают стандартные escape-последовательности:

```ocaml
let source_path = "src/main.e"
let error_message = "Syntax error: unexpected token \";\""
let multi_escape = "Line 1\nLine 2\tTabbed\rCarriage return"
```

Для путей файлов и регулярных выражений полезны **сырые строковые литералы**, отключающие экранирование:

```ocaml
let regex_pattern = {|[\w_][\w\d_]*|}  (* идентификаторы *)
let windows_path = {|C:\Users\Developer\project|} 
```
