# Строки

## `string`: Базовые строки

- Создание строк
```ocaml
let s1 = "Hello, World!"
let s2 = "OCaml"
let empty_string = ""
```
- Конкатенация
```ocaml
let greeting = "Hello, " ^ "OCaml!"  (* "Hello, OCaml!" *)
```
- Доступ к символам по индексу
```ocaml
let first_char = "hello".[0]  (* 'h' *)
```

## Модуль `String`

- Длина строки
```ocaml
let len = String.length "hello"  (* 5 *)
```
- Преобразование регистра
```ocaml
let upper = String.uppercase_ascii "hello"  (* "HELLO" *)
let lower = String.lowercase_ascii "HELLO"  (* "hello" *)
```
- Подстроки
```ocaml
let sub = String.sub "hello world" 6 5  (* "world" *)
```
- Поиск и замена
```ocaml
let index = String.index "hello" 'e'  (* 1 *)
let contains = String.contains "hello" 'l'  (* true *)
```
- Разделение строк 
```ocaml
let words = String.split_on_char ' ' "hello world"  (* ["hello"; "world"] *)
```
- (* Обрезка пробелов *)
```ocaml
let trimmed = String.trim "  hello  "  (* "hello" *)
```

## Форматирование строк

- Использование `Printf`
```ocaml
let name = "Alice"
let age = 25
let message = Printf.sprintf "Name: %s, Age: %d" name age
```
- Конкатенация нескольких строк
```ocaml
let full_message = String.concat ", " ["apple"; "banana"; "orange"]
(* "apple, banana, orange" *)
```
